## Вывод по лабораторной работе

В ходе выполнения лабораторной работы я освоил базовые принципы управления процессами и организации межпроцессного взаимодействия в ОС Linux на языке Си.

В процессе реализации своего варианта задания я:
* **Научился создавать дочерние процессы** с помощью функции `fork()` и управлять их жизненным циклом в связке `parent` — `child`.
* **Разобрался в устройстве неименованных каналов (`pipe`)**: понял концепцию файловых дескрипторов и то, за что отвечает каждая ячейка массива (`[0]` — чтение, `[1]` — запись).
* **На практике освоил перенаправление потоков ввода-вывода** с помощью функции `dup2()`, что позволило объединить изолированные независимые программы в единый рабочий конвейер.
* **Научился использовать системную утилиту `strace`** для низкоуровневой отладки программ на уровне ядра, отслеживая реальное поведение процессов и движение данных по каналам.
* **Закрепил навыки работы со стандартными системными библиотеками**, необходимыми для программирования в Unix-среде:
  * `<unistd.h>` — для работы с `fork`, `pipe`, `dup2`, `execl`;
  * `<sys/wait.h>` — для синхронизации и ожидания дочерних процессов;
  * `<string.h>` — для потоковой обработки строк.
